## 修复 yarn build 报错（已完成）

用户在 PowerShell 跑 `yarn build` 报错，要求全部解决。

**根因**：webpack 编译本身是成功的，唯一失败点是 `onBrokenLinks: 'throw'` 抓到的断链。报错都是 `/docs/intro`（docs 重组后该文件已不存在）。

**已做的修改**
1. 断链三处：`src/pages/index.js` 首页按钮 `to="/docs/tutorial/intro"`；`docusaurus.config.js` footer Tutorial 链接；`docs/tutorial/new/export.md` 里的 `(*)` 改成 `(#)`。
2. `docusaurus.config.js` 定制：title → `zhouzhou 的站点`、tagline → `记录 · 折腾 · 随手写点东西`、navbar title → `zhouzhou`；url → `https://zhouzhouj.github.io`、baseUrl → `/my-website/`（按 GitHub Pages 项目页假设，**自定义域名需改回 `/`**）；organizationName → `zhouzhouj`、projectName → `my-website`；editUrl → `https://github.com/zhouzhouj/my-website/tree/master/`；i18n → `zh-Hans`；导航栏 Life/ddd 改用 `type: 'docSidebar'` 绑定各自 sidebarId；footer 清掉与本站无关的 Docusaurus Community 区块，改为「文档 / 更多」两栏中文。
3. `sidebars.js`：tutorialSidebar 的 `dirName` 从 `'.'` 改为 `'tutorial'`（原先把 Life/ddd 也吞进去了，导致 LifeSidebar/dddSidebar 定义了却从未被使用）。
4. `_category_.json`：`docs/Life/detail` 的 label 拼写 `datail` → `detail`；`docs/tutorial/first/first` 的 label `new` → `second`（与 `docs/tutorial/new` 重名，会产生 `/docs/category/new-1` 重复路由）。
5. HTML 工具页：`docs/ddd/index.html` → **`static/tools/personality-analyzer.html`**（放 docs/ 下不会被发布、无路由）。同时修掉一个隐藏 bug：文件里 54 处 class 名用的是**非断行连字符 U+2011**（`rounded‑2xl`/`shadow‑lg`/`font‑bold`…），Tailwind 匹配不上，页面其实全程无样式；已全局替换为 ASCII `-`。并在 `docs/ddd/intro.md` 加了入口链接。
6. 更新 browserslist 数据库（`npx --yes update-browserslist-db@latest`），清掉陈旧提示。

**验证结果**：`yarn build` 退出码 0，`[SUCCESS] Generated static files in "build"`，无 broken links；locale 显示 `[zh-Hans]`；`build/tools/personality-analyzer.html` 等页面齐备，`docs/category/` 下已无 `datail` / `new-1`。

**环境坑（重要）**
- 本会话 **bash 的 shim 是坏的**（`dirname`/`cat`/`rm` 均 command not found），只能用 PowerShell。
- **PowerShell 工具的 stdout 不回显**，必须把输出重定向到文件再用 Read 读取。
- 读取时必须先剥掉 yarn/npx 输出的 **ANSI 转义序列**，否则 Read 报 "Cannot display content of binary file"。
- 后台 PowerShell 任务偶发 **PATH 不继承**（第二次 yarn build 报 `'docusaurus' 不是内部或外部命令`）；解决方式是在命令前手动 `$env:PATH = "F:\git\my-website\node_modules\.bin;" + $env:PATH`。
